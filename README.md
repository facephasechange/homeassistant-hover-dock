Option 2: Manual Installation

    Download the latest release from GitHub.

    Extract the downloaded archive.

    Copy the custom_components/hover_dock folder into your Home Assistant configuration directory:

    config/
    └── custom_components/
        └── hover_dock/

    Restart Home Assistant.

    Navigate to Settings → Devices & Services → Add Integration.

    Search for Hover Dock and complete the setup.

    Refresh your browser.

Usage

Move your mouse to the bottom edge of the Home Assistant interface to reveal the navigation dock.

The dock provides quick access to Developer Tools, Automations, Integrations, Entities, Settings, and other Home Assistant pages.

Use the dock's edit button to customize your shortcuts.

The dock automatically hides when not in use, keeping your dashboard uncluttered.

Not reviewed for HACS or Marketplace publishing.
